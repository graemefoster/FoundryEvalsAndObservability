## CI/CD workflows (in `sample/proposed/workflows/`; move to `.github/workflows/`)

These replace `deploy-and-evaluate.yml`, `local-checks.yml` and the earlier single gate file. Each test set has its own trigger, matching slide 14:

| File | Trigger | Runs | Blocks? |
| --- | --- | --- | --- |
| `agent-pr.yml` | Pull request | Lint, dry run and the prompt fact check (no Azure), then the development set (`demo-storyline`) vs baseline with a one-row tolerance (0.13) | Yes |
| `agent-main.yml` | Merge to main | Holdout vs baseline, tolerance 0.05 | No, it warns |
| `agent-release.yml` | Manual, or a `v*` tag | Drift set, must-pass on `next_action_success`, publishing scores and counts only; then a `production` environment approval | Yes |
| `_agent-eval.yml` | Called by the three above | Deploy, evaluate, then compare or save a baseline | - |

Also: `evaluate.py` now names each run after its dataset (for example `purchasing-next-action-evaluation-drift-lockbox`), and `check_prompt_facts.py` and `compare_to_baseline.py` are reformatted to pass the repo's ruff settings. ## First run

1. Move the four workflow files into `.github/workflows/`, and delete `deploy-and-evaluate.yml`, `local-checks.yml` and `agent-gate.yml`.
2. In the repo settings, create a `production` environment with yourself as a required reviewer.
3. Run each workflow manually with **write_baseline** ticked (PR gate, holdout, release). Download each `baseline-<dataset>` artifact and commit it as `sample/evaluation/baselines/<dataset>.json`. Check each baseline run looks right before trusting it.

Caveats:

- **Every evaluation deploys over the shared demo agent.** That's fine for a demo, but not how you'd run it for real; there you'd deploy each PR to its own agent version.
- **Tolerances depend on set size.** Foundry's 0.03 noise figure is for large optimizer runs. With 8 rows, one binary row moves a mean by 0.125, so the PR gate allows one row. On the 6-row drift set, the must-pass rule does the real work.
- **Untested in GitHub.** The workflows pass actionlint but haven't been run.
